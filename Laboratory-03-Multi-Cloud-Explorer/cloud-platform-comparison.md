</div>

## Comparison Questions

**1. Which cloud provider offers the broadest range of services?**

AWS offers the broadest range of services, with over 240 services covering nearly every use case, from compute and storage to AI and IoT. This is backed by AWS's own claim of being the "world's most comprehensive cloud." Its long head start since 2006 has allowed it to build out the deepest service catalog of the three providers.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure clearly integrates best with Microsoft technologies, since it's built by Microsoft itself. It connects smoothly with Windows Server, Active Directory, Microsoft 365, and .NET applications, and even lets companies sync their on-premises Active Directory with Microsoft Entra ID in the cloud.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform is the strongest in both areas. GCP created Kubernetes and still leads its development, offering the most mature managed Kubernetes service through GKE. It's also known for strong AI/ML tools like Vertex AI and TensorFlow, which are widely used for data-driven and AI-heavy workloads.

**4. Which cloud platform would you personally choose and why?**

I would choose Google Cloud Platform. The main reason is that AI is everywhere now, even e-commerce sites and everyday apps use AI for things like product recommendations, chatbots, and detecting fraud. GCP is strong in AI tools like Vertex AI and TensorFlow, so it feels like the best choice for building apps that use AI. GCP also created Kubernetes, so it's great for running modern apps too. Plus, it runs on the same powerful network as Google Search and YouTube, which already works well for millions of users.
