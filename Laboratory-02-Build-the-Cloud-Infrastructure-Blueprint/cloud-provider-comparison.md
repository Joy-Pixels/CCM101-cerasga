# Cloud Provider Comparison

This document compares the core infrastructure services offered by the
three leading public cloud providers, based on their official
documentation: Amazon Web Services (AWS), Microsoft Azure, and Google
Cloud Platform (GCP).

---

## Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Virtual Private Cloud |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (Azure AD) | Google Cloud IAM |

---

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**

AWS offers the broadest range of services. It has the largest cloud
ecosystem and the longest history in the market, giving it the most
mature and extensive lineup of tools across compute, storage,
databases, and AI. Because of this large market share, AWS
certifications are also considered some of the most valuable in the
cloud industry.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**

Microsoft Azure would be the best fit. Azure is built to integrate
smoothly with Microsoft technologies like Windows Server, Active
Directory, Microsoft 365, and SQL Server, so a company already using
those tools would have an easier time managing everything in one
ecosystem instead of dealing with compatibility issues between
different vendors.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**

Google Cloud Platform is the most recognized for AI, ML, and
Kubernetes. GCP is known for its strength in large-scale data
processing and machine learning, and Kubernetes itself actually
originated from Google's internal infrastructure before it became an
open-source project that the whole industry now uses.

**4. What similarities did you observe among the three cloud providers?**

All three providers offer the same core categories of service, just
under different product names. Compute, storage, networking, and IAM
exist on every platform, and each provider also offers serverless
computing (AWS Lambda, Azure Functions, Google Cloud Functions) along
with a pay-as-you-go pricing model instead of requiring big upfront
hardware purchases.
