# Laboratory Activity 1 - Mission 1: Welcome to the Cloud

## Mission Overview
Congratulations! You have been accepted as a Junior Cloud Infrastructure Engineer Trainee at 
CloudNova Technologies, a company specializing in cloud infrastructure, virtualization, and 
enterprise cloud solutions. As part of the onboarding process, every cloud engineer must first 
learn how to work inside a Linux environment, document their work professionally, and maintain 
a version-controlled portfolio using GitHub. This mission was completed using the KillerCoda 
Playground to build a personal Cloud Computing Portfolio on GitHub, which will serve as a 
professional workspace throughout the semester.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed
1. Launched an Ubuntu Linux Playground on KillerCoda and verified the terminal environment.
2. Created a new user (`cjerasga`) with Bash, a home directory, and sudo privileges, then logged 
   in to the new account.
3. Investigated the Linux environment and recorded system information (distribution, kernel 
   version, CPU info, memory, and disk space) inside `system-information.md`.
4. Built a folder structure (Documents, Notes, Reports, Screenshots) inside the home directory 
   and created `about-me.md` inside the Notes folder.
5. Created a public GitHub repository (`CCM101-cjerasga`) and structured it according to the 
   required Cloud Computing Portfolio format.
6. Documented the mission in this README.md and captured evidence through screenshots.

## Linux Commands Used
- `sudo adduser -m -s /bin/bash <username>`, `sudo passwd`, `sudo usermod -aG sudo`, `su -`
- `whoami`, `pwd`, `hostname`
- `lsb_release -d`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir`, `ls`, `nano`, `cat`

## Skills Learned
Through this activity, I learned basic Linux commands, how to manage users, and how to gather system information. I also learned how to structure a GitHub repository and write documentation using Markdown. Also, using KillerCoda helped me understand how cloud virtual machines work and gave me a better grasp of cloud computing basics, like how cloud sessions are temporary and why it's important to save work through GitHub.
